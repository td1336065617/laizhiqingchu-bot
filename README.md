# 表情包管理 · sticker_plugin

> 给 **QQ 群聊**（QQ 官方机器人 `qq_official` / `qq_official_webhook`，或非官方 OneBot v11 `aiocqhttp`）补上一套顺手的**表情包仓库**：用关键词收藏图片、随机斗图、按图精准删除，外加一个能备份、能恢复、能清空的 WebUI 管理页。

```text
群聊图片 ──► 添加{关键词}（回复图片 / 同消息带图 / 合并转发批量）
                 │
                 ▼
        MD5 去重 ──► stickers/{关键词}/ 图片文件 + index.json 索引
                 │
     来只{关键词} ◄──┤──► 列表{关键词}{页码}（管理员分页核对）
                 │
                 └──► 删图（回复图片按 MD5 定位）／删除{关键词}（二次确认整目录）

WebUI「表情包管理」页 ──► 管理员设置 · 立即备份（zip）· 上传恢复 · 清空
```

- **版本**：1.2.1 ｜ **平台**：`qq_official` / `qq_official_webhook` / `aiocqhttp`（AstrBot ≥ 4.13.0）｜ **作者**：td1336065617
- **数据位置**：AstrBot 数据目录下的 `stickers/`，通常是 `data/stickers/`

---

## 功能

### 📥 添加表情包
- 回复一条带图片的消息，发送 `添加{关键词}`，把图片批量收进该关键词。
- 同一条消息里直接带图也认（例如「添加蓝色大肥鱼」+ 图片一起发），不必先回复。
- 重复图片按 **MD5 自动跳过**，不会把同一张图在同一个关键词下存两遍。
- 一次回复多张图片时全部入库。

### 📦 合并转发批量入库
- `批量添加合并转发{关键词}`：先发命令，**90 秒内本人**再发合并转发，插件自动提取里面的图片批量入库。
- 只有命令发送者本人发的转发会被采纳，别人发的不会被误用。
- 兼容 QQ 官方实际推送的多种结构（摘要文本、顶层附件、嵌套元素、JSON 内容）；OneBot v11 通过 `get_forward_msg` 展开转发节点。

### 🎲 随机发送
- `来只{关键词}` 随机挑一张该关键词下的图片发出来。

### 🗂️ 关键词管理
- `列表{关键词}{页码}` 分页查看文件名，每页 10 张，页码可选。
- `删除{关键词}` 在 **60 秒内再发一次**即确认，删除整个关键词目录（不可恢复）。
- `统计` 查看关键词数、图片总数与图片数 Top 3。
- `屏蔽{关键词}` 让关键词进入"冻结"状态：禁止添加、禁止发送、禁止查看；`屏蔽列表` 查看全部，`解除屏蔽{关键词}` 恢复。

### 🗑️ 精准删除
- 回复要删的图片并发送 `删图`，按 **MD5** 在所有关键词中定位并删除（同图多份一并删除）。
- `删图{关键词}` 把删除范围限制在某个关键词里。
- `删图{关键词}{序号}` 按 `列表` 显示的序号删除单张。

### 🖥️ WebUI 管理页
- 入口：**AstrBot 管理面板 → 插件管理 → 表情包管理**。
- **管理员设置**：添加 / 移除管理员 ID（QQ 号或 openid），并设置存储上限（MB），保存后立即生效。
- **备份**：一键把索引、屏蔽列表与全部图片打包成 zip，内含 MD5 校验清单；列表可下载、可删除（仅删压缩包，不影响现有数据）。
- **恢复**：上传 zip 后先校验完整性再**合并式导入**，重叠图片按 MD5 跳过，并报告新增 / 覆盖 / 跳过 / 失败数量。
- **清空**：二次确认后删除全部关键词与图片（不影响管理员设置与屏蔽列表，建议先备份）。

### 📖 插件介绍

根目录附带 `intro.md`：安装「菜单导航」插件后，发送 `插件介绍` 可看到本插件的完整功能清单，
`插件介绍 表情包` 可只看本插件。

### 🎴 菜单与渲染
- `表情包管理菜单` 展示完整指令与权限，优先生成图片，环境不支持时回退为文字。
- 菜单自带**内置 Emoji 字体**，服务器不装字体也能正常显示。
- 附带 `menu.md`，可被「菜单导航」类插件聚合到统一的 `菜单` 指令下。

## 安装

1. AstrBot 版本需 **≥ 4.13.0**，并已启用 **QQ 官方机器人**（`qq_official` / `qq_official_webhook`）或 **OneBot v11**（`aiocqhttp`）适配器之一。
2. 在 AstrBot 插件页填入仓库地址安装，或手动放入插件目录：

```text
https://github.com/td1336065617/laizhiqingchu-bot
```

**首次使用**

| 步骤 | 操作 |
| --- | --- |
| 1 | 打开 **AstrBot 管理面板 → 插件管理 → 表情包管理** |
| 2 | 在「管理员设置」里添加你的 QQ 号 / openid（不加管理员，`列表`、`删图`、`统计` 等指令都会回「此指令仅限管理员」） |
| 3 | 按需调整存储上限（默认 200 MB，超出只写警告日志，不会阻止添加） |
| 4 | 在群里回复一张图片并发 `添加清楚`，再发 `来只清楚` 验证收发正常 |
| 5 | 发 `表情包管理菜单` 查看完整指令表 |

**手动部署**：把插件目录（`metadata.yaml`、`main.py`、`menu_renderer.py`、`menu.md`、`assets/`、`pages/`）放入 `AstrBot/data/plugins/sticker_plugin/`，再到 WebUI 插件管理页启用并重载。

## 指令

指令为**精确前缀触发**：必须以指令名开头，其余消息完全忽略（不做任何回复）。同时支持 `添加清楚` 与 `添加 清楚` 两种写法（关键词内部不能有空格），也兼容 QQ 官方指令面板自动补的 `/` 前缀（QQ 官方通道），例如 `/来只清楚`。

**所有人可用**

| 指令 | 说明 |
| --- | --- |
| `添加{关键词}` | 回复包含图片的消息，批量入库；同消息带图也可 |
| `批量添加合并转发{关键词}` | 先发命令，90 秒内本人发合并转发，自动批量入库 |
| `来只{关键词}` | 随机发送一张该关键词下的图片 |
| `表情包管理菜单` | 查看全部指令与权限 |

**仅管理员**（在 WebUI 的「管理员设置」中配置的 ID）

| 指令 | 说明 |
| --- | --- |
| `列表{关键词}{页码}` | 分页查看，每页 10 张，页码可选 |
| `删图` | 回复要删除的图片，按 MD5 自动定位并删除 |
| `删图{关键词}` | 仅在该关键词下按 MD5 删除 |
| `删图{关键词}{序号}` | 按序号删除单张 |
| `删除{关键词}` | 60 秒内再发一次确认，删除整个关键词目录 |
| `统计` | 关键词数、图片总数、图片数 Top 3 |
| `屏蔽{关键词}` | 屏蔽关键词（禁止添加 / 发送 / 查看） |
| `屏蔽列表` | 查看已屏蔽的关键词 |
| `解除屏蔽{关键词}` | 解除屏蔽 |

**WebUI 管理页**：管理员设置、备份、恢复、清空，不走聊天指令。

## 配置

插件**不提供 AstrBot 原生配置表单**（没有 `_conf_schema.json`），全部配置在 **AstrBot 管理面板 → 插件管理 → 表情包管理** 页维护，保存后立即生效。

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `admin_users` | 空 | 可使用管理指令的 ID 列表（QQ 号或 openid），添加 / 移除会自动保存 |
| `max_storage_mb` | 200 | 存储上限（MB），超出后只记录警告日志，不会阻止写入 |

菜单渲染的可选环境变量（一般无需设置，渲染器会自动挑选可用方案）：

| 环境变量 | 说明 |
| --- | --- |
| `STICKER_MENU_RENDERER` | 指定菜单渲染器：`chromium`、`firefox`、`wkhtmltoimage`、`pillow` 等 |
| `STICKER_MENU_FONT` / `STICKER_MENU_FONT_INDEX` | 指定中文字体文件路径与 TTC 字体面索引 |
| `STICKER_MENU_EMOJI_FONT` / `STICKER_MENU_EMOJI_FONT_INDEX` | 覆盖 Emoji 字体路径与字体面 |

## 数据与存储

数据目录按 AstrBot 官方规范解析（`get_astrbot_data_path()`），最终为 AstrBot 数据目录下的 `stickers/`，即通常的 `data/stickers/`：

```text
stickers/
├── index.json               # {"关键词": ["文件名1.png", ...]}
├── blocked_keywords.json    # 屏蔽关键词列表
├── 关键词A/
│   └── 1710000000000_1234.png
└── 关键词B/

sticker_backups/             # WebUI 备份产生的压缩包
└── sticker_backup_20260813_150000_1234.zip
sticker_menu_cache/          # 菜单图片缓存
config/sticker_plugin_config.json   # 插件自管理配置（管理员列表 / 存储上限）
```

**备份**：WebUI 点「立即备份」即得标准 zip，内含 `index.json`、`blocked_keywords.json`、全部图片与 `manifest.json` 校验清单（关键词数、图片数与逐文件 MD5）。打包解包只用 Python 标准库 `zipfile`，不依赖第三方 SDK 或云服务。

**迁移**：把 zip 拷到另一台机器 → 装好插件 → 打开「表情包管理」页上传导入（合并式，重叠图片按 MD5 跳过）。

## 常见问题

**发指令没反应？**
指令是**精确前缀**匹配，只有以指令名开头的消息才会被处理，其余消息会被完全忽略。另外确认这是 QQ 官方或 OneBot v11 适配器下的群聊或私聊，以及机器人确实收到了这条消息 —— 非 @ 场景、平台未推送时插件收不到消息。仍未响应时看插件日志里的 `StickerPlugin 事件` 与 `消息链` 两行。

**回「关键词不合法」？**
说明书里的 `{关键词}` 是占位符，请替换成真实关键词，且关键词内部不能有空格（`来只 清楚` 不合法，应写成 `来只清楚`），也不能与指令名重名或包含路径分隔符等非法字符。

**提示「此指令仅限管理员」？**
`列表`、`删图`、`删除`、`统计`、`屏蔽*` 都是管理指令。到 WebUI「管理员设置」里把操作者 ID 加进去（QQ 号或 openid），保存后立即生效；日志里会打印 `管理员校验未通过` 与当前管理员列表，方便核对 ID 是否写错。

**添加失败 / 提示未获取到图片？**
插件按「引用消息里的图片 → 当前消息自带的图片 → 引用里的合并转发」的顺序找图，都拿不到才报错。QQ 官方与 OneBot 适配器是否下发引用消息的完整内容取决于 AstrBot 版本与协议端实现，请实测确认；被引用的图片取不到时，插件按设计忽略该消息。合并转发请改用 `批量添加合并转发{关键词}`，且**必须由发命令的本人**在 90 秒内发送。

**为什么提示"跳过 N 张重复"？**
同一关键词下已存在 MD5 相同的图片时会被跳过，这是去重，不是失败。同一张图想收进另一个关键词，换个关键词再添加即可。

**图片删不掉 / 怕删错范围？**
`删图` 删除的是"与回复图片 MD5 相同"的全部文件，同一张图存在于多个关键词时会一并删除；只想删某个关键词下的，用 `删图{关键词}` 限定。`删除{关键词}` 是整目录删除且不可恢复：第一次发送只是挂起请求，60 秒内再发一次才真正执行，超时或关键词不一致会提示重新发送。

**日志出现「存储已超过 200MB」？**
这是容量警告，不影响继续添加。到 WebUI「表情包管理」页把存储上限调大，或清理不需要的关键词后重新备份。

**菜单显示成一堆文字，不是图片？**
说明当前环境没有找到可用的渲染器。插件依次尝试 Chromium 系、Firefox、`wkhtmltoimage`，再回退 Pillow，全部不可用才输出文字版菜单。可以安装其中一个渲染器，或用 `STICKER_MENU_RENDERER` 显式指定；中文与 Emoji 依赖字体，Pillow 回退会显式加载简体中文字体面，Emoji 使用插件内置字体。

## 开发

```text
sticker_plugin/
├── main.py                  # Star 入口、指令分发、Web API、备份 / 恢复
├── menu_renderer.py         # 菜单 HTML / PNG 渲染与文字回退
├── menu.md                  # 供「菜单导航」类插件聚合的菜单文本
├── metadata.yaml            # 插件元信息（名称、版本、平台、仓库）
├── pages/manage/index.html  # WebUI 管理页（管理员 / 备份 / 恢复 / 清空）
├── assets/fonts/            # 内置 Noto Color Emoji 字体及其许可
└── tests/                   # 菜单渲染回归测试
```

- **依赖**：只用 Python 标准库与 AstrBot 官方 SDK，无第三方 pip 依赖。
- **存储**：`stickers/index.json` 记录关键词到文件名的索引，图片以真实文件落地；索引会在物理文件丢失时自动清理失效条目。
- **扩展**：新增指令在 `main.py` 的 `on_message` 前缀分发里登记，注意把更长、更具体的前缀写在前面（例如 `屏蔽列表` 必须先于 `屏蔽` 判断）；改完记得同步 `MENU_TEXT`、`menu.md` 与本文件的指令表。

## 更新

1. `git pull` 拉取最新代码，并查看 [CHANGELOG.md](CHANGELOG.md) 了解本次改动；
2. 把插件文件同步到 `AstrBot/data/plugins/sticker_plugin/`；
3. 在 AstrBot WebUI 插件管理页重载插件（或重启 AstrBot）。

`stickers/`、`sticker_backups/`、`sticker_menu_cache/` 与 `config/` 下的数据不会被覆盖，更新不会丢失表情包。

## Windows 支持

Windows 上 Chromium / Firefox 通常不在 PATH，插件已内置常见安装路径探测
（Chrome / Edge / Firefox），并内置 Windows 系统字体（微软雅黑 / 黑体 / 宋体 / 等线）
与 Emoji 字体（Segoe UI Emoji）。

若仍拿不到图片，可显式指定（不改代码）：

```bat
set STICKER_MENU_RENDERER=C:\Program Files\Google\Chrome\Application\chrome.exe
set STICKER_MENU_FONT=C:\Windows\Fonts\msyh.ttc
set STICKER_MENU_FONT_INDEX=0
```
